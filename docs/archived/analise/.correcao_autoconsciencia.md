## 1. Resumo Executivo (Para Gestão)

**Assunto:** Auditoria do módulo de "Autoconsciência" (Source Indexer) do Projeto FazAI NG.

**Contexto:**
O FazAI possui uma capacidade rara em sistemas de IA: a "Metacognição". Ele é capaz de ler, entender e indexar seu próprio código-fonte em tempo real. Isso permite que a IA responda perguntas sobre sua própria arquitetura ("Como eu me conecto ao Google?") e evolua suas capacidades sem intervenção humana constante.

**Achados:**
O sistema está funcional e já indexou mais de 4.500 vetores de conhecimento. No entanto, identificamos dois riscos operacionais:
1.  **Risco de Permissão:** O sistema tenta salvar seu "estado de memória" em um diretório de sistema (`/opt/fazai`), o que pode falhar em ambientes sem privilégios de administrador (root), causando perda de performance.
2.  **Perda de Contexto:** Parte significativa do código está sendo classificada como "Desconhecida" (Unknown), o que reduz a precisão da IA ao buscar informações específicas sobre testes e agentes.

**Recomendação:**
Aplicar as correções técnicas anexas para garantir que o sistema rode de forma robusta em qualquer ambiente (Desenvolvimento ou Produção) e classifique corretamente 100% do seu conhecimento.

## 2. Análise Técnica (GeGe) 👩‍💻

Mano, o sistema tá lindo, mas precisa desses ajustes pra ficar "bala":

### A. Correção de Caminhos (`STATE_FILE_PATH`)
*   **Atual:** Hardcoded para `/opt/fazai/data/`.
*   **Problema:** Se o Roginho rodar como user normal (sem sudo), crasha ou não salva o incremental.
*   **Solução:** Mudar para usar `process.cwd()/data` ou variável de ambiente. Isso torna o projeto "portable".

### B. Categorização "Unknown"
*   **Atual:** O `PATH_CONFIG` não tinha entradas para `tests/` e `genaisrc/`.
*   **Problema:** Testes são vitais para entender *como* usar o código. Se a IA acha que é "unknown", ela ignora.
*   **Solução:** Adicionei as chaves no config.

### C. Proposta do Maestro Planner (O Cérebro Agêntico)
Para implementar a visão do Roginho de usar o Phi-3 como "Maestro", precisamos criar o arquivo `genaisrc/planner.genai.mjs`.

**Prompt Proposto para o Planner (Phi-3):**
> "Você é o MAESTRO. Receba a ordem vaga. Pense em Inglês. Simplifique (Navalha de Ockham). Decomponha em JSON. Não instale Apache se Python resolve."

## 3. Plano de Execução (Para o Agente Executor)

Se aprovado pelo Grok, execute os passos abaixo na ordem:

### Passo 1: Aplicar Correções no Indexador
Aplique o patch anexo para corrigir os caminhos e categorias.

```bash
# Instrução para o Agente:
patch src/services/source-indexer.ts < docs/analise/.1-source-indexer-paths.ts.diff
```

### Passo 2: Criar o Maestro Planner
Crie o arquivo `genaisrc/planner.genai.mjs` com o conteúdo abaixo:

```javascript
script({
    title: "FazAI Task Planner",
    description: "Maestro que decompoe tarefas complexas usando Phi-3",
    model: "ollama:phi3",
    temperature: 0.1
});

const task = env.vars.task;
if (!task) throw new Error("Task required");

$\`
    You are the SYSTEM MAESTRO.
    Input: "${task}"

    GOAL: Create a lean, sequential execution plan.
    RULES:
    1. Prefer simple tools (python http.server > nginx).
    2. Use existing binaries (grep, awk, sed) over installing new ones.
    3. Output strictly JSON.

    JSON FORMAT:
    {
      "plan_id": "slug",
      "steps": [
        { "id": 1, "cmd_hint": "command attempt", "validation": "how to check success" }
      ]
    }
    \`
```

### Passo 3: Re-indexar
Após aplicar as correções, force uma re-indexação para corrigir as categorias "unknown".

```bash
npm run build
./bin/fazai index --force
```
