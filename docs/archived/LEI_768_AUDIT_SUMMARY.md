## 3. PROVIDER_FALLBACK_ORDER Analysis

### Current Status

No typo found in `fazai.conf.example`. The issue description mentions looking for "googl,eollama" but this appears to be a hypothetical case that the validation should catch.

### Protection Implemented

The Zod schema (`src/config/schema.ts`) now includes:

```typescript
.refine(
  (val) => {
    const lower = val.toLowerCase();
    if (lower.includes("googl,e") || lower.includes("eollama")) {
      return false;
    }
    return true;
  },
  { message: "Provider list contains typos (e.g., 'googl,eollama' should be 'google,ollama')" }
)
```

This will catch the specific typo mentioned in the issue, plus detect:
- Invalid provider names
- Duplicate providers
- Common typo patterns
