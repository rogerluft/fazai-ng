# Fluxograma: Operação Agênica - EXEC (Modo Default)

**Versão**: 1.0.0  
**Tipo**: Modo de Administração Linux (Comportamento Padrão)  
**Comando**: `fazai "tarefa"` ou simplesmente `fazai`  
**Objetivo**: Gerar e executar comandos Linux para administração de sistemas

---

## 📋 Visão Geral

O modo **EXEC** (default invisível) é o **coração do FazAI**: transforma linguagem natural em comandos Linux executáveis, com decomposição de tarefas complexas, fallbacks inteligentes, auto-aprendizado e pesquisa web automática quando necessário.

**Este é o modo mais complexo**, envolvendo:
- GenAIScript (fazai-core.genai.mjs) para loop agêntico
- RAG multi-collection (KB + Learning + Source para metacognição)
- Task decomposition (DAG Executor)
- Command fallbacks
- Retry automático com abordagens alternativas
- Captura de learning pós-sucesso

### 4. **Retry Mechanism** (Inteligente!)

```typescript
// tryAlternativeApproach():
1. Max 2 cycles de retry
2. Para cada cycle:
   a. Pede alternativas para LLM com:
      - Comando que falhou
      - Output de erro
      - Lista de comandos JÁ tentados (não repetir!)
   b. LLM gera NOVA sequência de comandos
   c. Executa alternativas uma a uma
   d. Se alguma suceder → break
   e. Se todas falharem → próximo cycle
3. Se após 2 cycles, ainda falhou → skip

// Exemplo:
Tentativa 1: apt install nginx
  ❌ Falha: "Unable to locate package"
  
Retry 1: LLM sugere → apt update && apt install nginx
  ✅ Sucesso!
```

## 🎓 Modos Avançados (Experimentais)

### Task Decomposition

Ativação: Detecção automática ou flag `--decompose`

```bash
$ fazai --decompose "configurar servidor web completo com SSL"
```

**Pipeline**:
1. `task-decomposer.ts` → Decompõe em SubTasks com dependencies
2. `dag-executor.ts` → Resolve DAG topologicamente
3. Para cada subtask:
   - Verifica deps prontos
   - Checa se já instalado (verificationCommand)
   - Instala se necessário (installCommand)
   - Executa comando principal
4. Tracking de progresso

**Exemplo**:
```
Task: "configurar servidor web completo com SSL"

SubTasks:
1. [task-1] Verificar nginx instalado
   Dependencies: []
   
2. [task-2] Instalar nginx
   Dependencies: [task-1]
   
3. [task-3] Instalar certbot
   Dependencies: []
   
4. [task-4] Configurar virtual host
   Dependencies: [task-2]
   
5. [task-5] Gerar certificado SSL
   Dependencies: [task-3, task-4]
   
6. [task-6] Reload nginx
   Dependencies: [task-5]

Execution Order (topological):
task-1 || task-3 (parallel)
  ↓         ↓
task-2    task-4
  ↓         ↓
    task-5
      ↓
    task-6
```

### GenAI Agentic Loop

Ativação: `ENABLE_PREVIEW_FEATURES=true` em fazai.conf

**Pipeline**:
1. `genai-runner.ts` → Spawns `npx genaiscript run fazai-core.genai.mjs`
2. Loop (max 5 iterações):
   a. `qdrant_multi_search` → Busca contexto relevante
   b. `reflect` → Meta-cognição (LLM avalia produtividade)
   c. `qdrant_upsert_insight` → Salva insights
   d. `check_loop_status` → Decide se continua
3. Retorna resposta enriquecida com insights

**Uso**: Perguntas complexas que exigem múltiplas buscas e reflexão.
