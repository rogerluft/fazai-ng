# Fluxograma: Operação Agênica - `fazai ask`

**Versão**: 1.0.0  
**Tipo**: Modo de Consulta Simples (Perguntas Gerais)  
**Comando**: `fazai ask "pergunta"`  
**Objetivo**: Responder perguntas gerais sem execução de comandos

---

## 📋 Visão Geral

O modo `ask` é uma **interface conversacional leve** para consultas gerais à IA. Diferente do modo `exec` (default), **NÃO executa comandos no sistema**, apenas responde perguntas.

## ⚙️ Detalhes Técnicos Críticos

### 1. **Cache Semântico** (`SemanticCache`)

```typescript
// Funcionamento:
1. Gera embedding da query (OpenAI text-embedding-3-small)
2. Compara com cache via cosine similarity
3. Threshold: 0.90 (alta similaridade)
4. TTL: 1 hora
5. LRU eviction quando cheio
```

**Não usa Qdrant**. Cache in-memory (Map) para zero latência.

### 2. **RAG Enrichment** (`enrichWithRAG` → `neuralQuery`)

```typescript
// Pipeline:
1. Gera embedding da pergunta
2. Busca paralela em 3 collections:
   - fazai_kb (peso 0.5)       → Conhecimento técnico
   - fazai_learning (peso 0.3) → Padrões aprendidos
   - fazai_memory (peso 0.2)   → Histórico de conversas
3. Fusion scoring: (score * peso) + recency boost
4. Retorna top 5 resultados fusionados
5. Injeta no system message
```

**Graceful degradation**: Se Qdrant offline, pula RAG e continua.

### 3. **Provider Fallback Chain**

```
Ordem preferencial:
ollama → openrouter → anthropic → openai → google → llama

Critérios de fallback:
- Connection timeout
- Rate limit (429)
- Service unavailable (503)
- Memory allocation errors (Ollama)

NÃO faz fallback em:
- Invalid API key (401)
- Invalid request (400)
- Model not found (404)
```

### 4. **ECOA Tools** (Autonomous Tool Execution)

| Tag | Trigger | Ação |
|-----|---------|------|
| `[[WEB: termo]]` | Detecta na resposta LLM | 1. Chama Perplexity Sonar API<br/>2. Follow-up LLM com resultado |
| `[[SAVE: texto]]` | Detecta na resposta LLM | 1. Gera embedding<br/>2. Upsert em `fazai_memory`<br/>3. Follow-up LLM |
| `[[READ: termo]]` | Detecta na resposta LLM | 1. Busca em `fazai_memory`<br/>2. Follow-up LLM com memórias |

**Fluxo**: LLM gera tag → `detectEcoaTags` → `executeEcoaTool` → Follow-up LLM call

### 5. **Personality Injection**

```typescript
// System message structure:
`
Você é o FazAI, uma IA avançada com personalidade única...

ESTILO E TOM (Siga estritamente):
${personalityContext} // ← Carregado de fazai_personality

--- CONTEXTO RECUPERADO (RAG) ---
${ragContext}          // ← Carregado de KB/Learning/Memory
--- FIM CONTEXTO RAG ---
`
```

**Cache de 1 hora** para evitar re-query de personality (raramente muda).

## 🔬 Exemplo Completo de Execução

```bash
$ fazai ask "Como usar comando find?"
```

### Trace Interno:

```
1. bin/fazai → carrega fazai.conf
2. app.ts → detecta "ask"
3. commands/ask.ts → extrai "Como usar comando find?"
4. askAI.ts → lookup cache (MISS)
5. enrichWithRAG → busca em kb/learning/memory
   ├─ fazai_kb: 2 resultados (comando find, exemplos)
   ├─ fazai_learning: 1 resultado (uso recente)
   └─ fazai_memory: 0 resultados
6. Fusion score → top 3 contextos
7. Build system message:
   ├─ Personality: "Seja direto, técnico..."
   ├─ RAG: "[kb] (0.87) find comando busca arquivos..."
   └─ Prompt: "Como usar comando find?"
8. LLM call (Anthropic Claude)
   ├─ Tenta anthropic → SUCESSO
   └─ Stream response
9. detectEcoaTags → nenhuma tag detectada
10. Store in cache (embedding + response)
11. Output para usuário
```
