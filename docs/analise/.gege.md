## 1. Visão Geral Atualizada

Esta revisão incorpora o feedback crítico para evitar fragmentação de arquivos e garantir verificações de sistema mais robustas.

**Mudanças Chave:**
1.  **Unificação Agêntica:** A lógica do "Maestro" foi integrada ao `genaisrc/reflect.genai.mjs`, transformando-o em um script de **Raciocínio (Reasoning)** com dois modos: `plan` (Proativo) e `reflect` (Retroativo).
2.  **Checagem Robusta:** Substituímos `which` por uma verificação híbrida (`systemctl` para serviços, `which` para binários) no `system-info.ts`.
3.  **Logs Seguros:** O Logger agora trata objetos mistos com segurança, evitando perda de dados.
4.  **Watchdog Configurável:** Limites de memória agora respeitam variáveis de ambiente.

## 2. Análise Técnica e Correções (Diffs Gerados)

Abaixo estão os arquivos de correção e implementação, separados para facilitar a revisão e aplicação.

### 2.1. Centralização de Configuração (`src/config.ts`)
Garante que os modelos locais e remotos sejam lidos exclusivamente de `/etc/fazai/fazai.conf`.

**Arquivo:** `docs/analise/.1-config.ts.diff`

### 2.2. Coleta de Contexto Híbrida (`src/system-info.ts`)
Expande a coleta com verificação real de estado (`is-active`) para serviços críticos (Nginx, Apache, Docker) e detecção de binários para ferramentas (Python, Git).

**Arquivo:** `docs/analise/.2-system-info.ts.diff`

### 2.3. Raciocínio Unificado (`genaisrc/reflect.genai.mjs`)
Transforma o script de reflexão em um motor de raciocínio multimodal.
- **Modo Plan:** Recebe `task`, usa Phi-3/Llama, gera JSON de execução com dependências.
- **Modo Reflect:** Analisa `learnings` do Qdrant e gera insights.

**Arquivo:** `docs/analise/.3-reflect.genai.mjs.diff` (Modificação do existente em vez de criar novo)

### 2.4. Watchdog Configurável (`src/services/watchdog.ts`)
Serviço de monitoramento com limite de memória via `FAZAI_WATCHDOG_MEM_MB`.

**Arquivo:** `docs/analise/.4-watchdog.ts` (Novo Arquivo)

### 2.5. Logger Seguro (`src/logger.ts`)
Tratamento aprimorado para logs mistos (String + Object) no arquivo de log.

**Arquivo:** `docs/analise/.5-logger.ts.diff`
