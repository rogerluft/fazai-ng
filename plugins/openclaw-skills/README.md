# OpenClaw Skills (Fazai Bridge)

This folder contains tools (skills) intended to be dropped into the OpenClaw workspace
(`~/.openclaw/workspace/skills/`) to bridge OpenClaw's engine with Fazai's functionality.

## Installation

To use this within OpenClaw, copy the `.js` files in this directory to your OpenClaw skills folder:

```bash
mkdir -p ~/.openclaw/workspace/skills/fazai_memory_search
cp fazai_memory_search.js ~/.openclaw/workspace/skills/fazai_memory_search/index.js
```
