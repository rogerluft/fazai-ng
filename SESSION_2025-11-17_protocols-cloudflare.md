## 🔧 Usage Examples

### Cloudflare
```bash
# List all zones
fazai cloudflare zones

# List DNS records
fazai cloudflare dns list <zoneId>

# Create DNS record
fazai cloudflare dns create <zoneId> A subdomain 192.168.1.1 true

# Purge cache
fazai cloudflare cache purge <zoneId>

# Set SSL to Full (strict)
fazai cloudflare ssl set <zoneId> strict
```

### Sync
```bash
# Sync repo changes to production
fazai sync

# Dry run
fazai sync --dry-run
```
