● O Artigo do Daniel Avila - "2024 Tunnel Vision"

  O Problema

  O Claude Code tem um vício de buscar informações de 2024 mesmo estando em 2025. Quando você pede:
  - "Tutorial de LangChain" → ele busca "LangChain tutorial 2024"
  - "Documentação React" → ele busca "React docs 2024"

  Isso acontece porque os LLMs ficam "presos" na época dos dados de treinamento. O GPT-3 tinha o mesmo problema em 2020, buscando coisas de 2019.

  Resultado: Você recebe resultados desatualizados, documentação antiga, tutoriais obsoletos.

  ---
  A Solução: Um Hook Simples

  Daniel criou um pre-tool hook que intercepta as buscas e troca o ano automaticamente:

  npx claude-code-templates@latest --hook=pre-tool/update-search-year --yes

  Como Funciona

  | Antes                       | Depois                      |
  |-----------------------------|-----------------------------|
  | "LangChain tutorial 2024"   | "LangChain tutorial 2025"   |
  | "React best practices 2024" | "React best practices 2025" |

  O hook é transparente - você não muda nada no seu workflow. Ele simplesmente:
  1. Intercepta a query de busca (pre-tool)
  2. Detecta referências a anos antigos
  3. Substitui pelo ano atual
  4. Envia a busca corrigida

  ---
  Por que é Genial

  - Mínimo e cirúrgico - só muda o ano, não quebra nada
  - Zero configuração - instala e funciona
  - Transparente - você nem percebe que está funcionando

  Você pode ver o código do hook em: https://www.aitmpl.com/component/hook/update-search-year

  ---
  Instalação

  # Instalar o hook
  npx claude-code-templates@latest --hook=pre-tool/update-search-year --yes

  Depois disso, suas buscas web vão retornar resultados de 2025 automaticamente!

  Não mano, é SUPABASE - é tipo um Firebase open-source:

  | Supabase       | O que faz                                   |
  |----------------|---------------------------------------------|
  | Database       | PostgreSQL gerenciado                       |
  | Auth           | Autenticação pronta (Google, GitHub, email) |
  | Storage        | Upload de arquivos                          |
  | Realtime       | WebSockets pra updates em tempo real        |
  | Edge Functions | Serverless functions                        |

  O Supabase Toolkit provavelmente tem agentes/skills pra:
  - Gerenciar tabelas/schemas
  - Configurar Row Level Security (RLS)
  - Criar migrations
  - Integrar auth

  É concorrente do Firebase do Google, só que open-source e baseado em PostgreSQL em vez de NoSQL.
