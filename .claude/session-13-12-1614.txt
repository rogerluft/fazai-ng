  🔴 BUGS CRÍTICOS (Urgência: ALTA)

  1. Conflito de Types - @/types/jarvis vs @/types/fazai

  Impacto: Breaking Change - TypeScript não resolve imports
  - Arquivos importam de @/types/jarvis mas só existe @/types/fazai.ts
  - Definições de coleções inconsistentes: jarvis_* vs fazai_*
  - Fix: Criar jarvis.ts re-export ou corrigir todos imports

  2. Memory Search - Semantic Search Não Implementado

  Arquivo: web/app/api/memory/search/route.ts:26-39
  // TODO: Implement semantic search when query is provided
  const query = searchParams.get("query"); // Obtido mas NUNCA usado
  Impacto: Busca semântica falha silenciosamente, retorna sempre últimos N registros

  3. Personality Traits - Sem Persistência em Qdrant

  Arquivo: web/app/api/personality/traits/route.ts
  export async function POST(request: Request) {
    const body = await request.json();
    return NextResponse.json({ success: true, trait: body });
    // ❌ Apenas retorna, não persiste em Qdrant
  }
  Impacto: Traits adicionados desaparecem ao recarregar

  4. Knowledge Base - Create/Delete Retorna 501

  Arquivo: web/app/api/knowledge/route.ts
  return NextResponse.json({
    error: "Knowledge creation not implemented yet",
  }, { status: 501 });
  Impacto: Usuário não consegue criar/deletar conhecimento

  5. Rules API - Mock Hardcoded

  Arquivo: web/app/api/rules/route.ts
  const mockRules = [/* hardcoded */];
  export async function GET() {
    return NextResponse.json(mockRules); // Sempre retorna fake data
  }
  Impacto: Regras criadas não persistem, UI sempre mostra 1 regra fake

  6. Collection Names Mismatch

  Conflito entre:
  - types/fazai.ts: jarvis_personality, jarvis_memory, etc.
  - lib/qdrant.ts: fazai_personality, fazai_memory, etc.

  Impacto: Queries falham silenciosamente por nome de coleção inválido
